# Gym Week

A minimal weekly gym planner. No build step — open `index.html` in a browser.

- **Each day**: write a short plan (e.g. "Upper – bench heavy") and tick it off when done.
- **Saved workouts**: keep a list of your workouts at the bottom, then use "+ Add workout" on any day to add one.
- **New week**: clears the ticks and keeps your plan.

Data is saved in your browser (localStorage).
